      ⚡ GitHub link (live scans)

      A GitHub token lets the SCAN button start a live scan and lets the app set up push. The token is stored only on this device. How to make one

      1. Open github.com → Fine-grained token.
      2. Repository access: Only select repositories → this repo.
      3. Permissions: Actions, Secrets and Variables: Read & write. Contents: Read.
      4. Generate, copy, and paste it below.

      📲 Install on iPhone

      1. Open this page in Safari.
      2. Tap Share (□↑) → Add to Home Screen.
      3. Open OLED Hunt from your home screen, then enable push here.

      iOS only allows push in the installed app (iOS 16.4+). The installed app has its own storage, so connect GitHub inside the installed app.
